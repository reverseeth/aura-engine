01O que é a Aura
Um sistema que roda dentro do Claude Code.

A Aura é um sistema de construção de marcas de ecommerce que roda dentro do Claude Code. Tecnicamente, ela é três coisas:

  • Skills. Fases executáveis que cobrem o negócio inteiro: pesquisa de produto, mercado e concorrentes, oferta, copy, página, criativos, tráfego pago e retenção. Você dispara cada fase digitando o nome dela.
  • Regras. Instruções permanentes de como a inteligência artificial trabalha: padrões de qualidade, checagens automáticas antes de qualquer lançamento e proteções pros seus dados.
  • Uma base de conhecimento conectada. Centenas de frameworks de marketing, copy e mídia paga catalogados (Schwartz, Hopkins, Cialdini, Hormozi). Antes das decisões importantes, a Aura consulta essa base. É o que fundamenta as recomendações em método, não em improviso.
Como as fases se conectam Cada fase salva o que descobriu na pasta workspace/ e a seguinte lê esses arquivos antes de começar. A pesquisa alimenta a oferta, a oferta alimenta a copy, a copy alimenta a página. Nada se perde e você nunca repete informação.

03Instalação
Dois comandos e a Aura está na sua máquina.
Mac

Abra o Terminal e rode, um de cada vez:

1 · instalar o claude code
curl -fsSL https://claude.ai/install.sh | sh
2 · baixar a aura e abrir
git clone https://github.com/reverseeth/aura-engine.git
cd aura-engine
claude

Se o Mac pedir pra instalar as "Command Line Tools" quando você rodar o git, aceite. É o instalador oficial da Apple.

Windows

Abra o PowerShell e rode, um de cada vez:

1 · instalar o claude code
irm https://claude.ai/install.ps1 | iex
2 · baixar a aura e abrir
git clone https://github.com/reverseeth/aura-engine.git
cd aura-engine
claude

Se o comando git não existir, instale primeiro em git-scm.com/download/win (instalação padrão) e abra o PowerShell de novo.

O que deve acontecer Na primeira vez, o Claude Code pede login. Entre com a conta da sua assinatura. Quando o campo de digitar aparecer, a Aura carregou junto: ela vive dentro dessa pasta.
Nunca apague a pasta aura-engine pra "reinstalar" Todo o seu trabalho vive na pasta workspace/, dentro de aura-engine, e existe só no seu computador. Apagar a pasta apaga o trabalho junto. A Aura se atualiza sozinha todo dia; reinstalar nunca é necessário.
04O atalho aura + permissões
Digite aura. Só isso, todo dia.

Depois desta etapa, abrir a Aura vira uma palavra: você digita aura no terminal e o Claude Code abre na pasta certa, sem pedir permissão a cada passo.

terminal
$aura
abrindo o Claude Code em ~/aura-engine…
✻ Aura Engine · pronta pra trabalhar.
>market research
O modo sem interrupções

Por padrão, o Claude Code pede permissão antes de cada ação. Numa sessão longa da Aura isso vira dezenas de aprovações que quebram o fluxo. O modo bypass permissions desliga essas pausas, e o atalho abaixo já vem com ele ligado.

Na primeira vez, o Claude mostra um aviso e pede uma confirmação única (aceite). O nome da flag é dramático de propósito: com ela, o Claude age sem pedir aprovação a cada passo. Use esse modo na pasta da Aura, que tem as próprias proteções (como o guarda que bloqueia mecanicamente qualquer commit dos seus dados), e evite usá-lo em outras pastas.

Mac

Cole no Terminal (cria o atalho e ativa no shell atual):

atalho aura · mac
echo "alias aura='cd ~/aura-engine && claude --dangerously-skip-permissions'" >> ~/.zshrc
source ~/.zshrc

A Aura cria um atalho aura básico sozinha na primeira sessão. O comando acima instala a versão completa, com o modo sem interrupções; se o básico já existir, o novo prevalece.

Windows

Cole no PowerShell (cria o atalho no seu perfil):

atalho aura · windows
if (!(Test-Path $PROFILE)) { New-Item -ItemType File -Path $PROFILE -Force }
Add-Content $PROFILE 'function aura { Set-Location "$HOME\aura-engine"; claude --dangerously-skip-permissions }'
. $PROFILE

Se o PowerShell reclamar de "execution policy" ao abrir, rode uma vez: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned e confirme.

Teste Feche o terminal, abra de novo e digite aura. Se o Claude Code abrir na pasta aura-engine, está pronto. (Se você clonou a Aura em outro caminho, ajuste o atalho.)
05Conectar a base de conhecimento
O que fundamenta as recomendações.

A base de conhecimento reúne centenas de frameworks de marketing, copy e mídia paga prontos pra consulta. É ela que sustenta as decisões da Aura em cada fase.

No Claude Code (automático)

O próprio Aura Engine já vem com a base registrada — falta só guardar a sua chave de acesso. Rode uma vez no terminal, fora de uma sessão do Claude (outra aba, ou Ctrl+C duas vezes pra sair):

guardar a chave de acesso · roda uma vez
echo 'export AURA_KEY="AURADTCACCESS"' >> ~/.zshrc

Depois abra um terminal novo e entre no Claude Code (comando aura). Na primeira vez vai aparecer um aviso perguntando se você aprova o servidor aura — aprove, e está conectado.

Recusou o aviso sem querer? Rode fora de uma sessão do Claude e abra o Claude Code de novo pra aprovar:

reexibir o aviso de aprovação · claude code
claude mcp reset-project-choices
No aplicativo Claude Desktop
  1. Abra Settings → Connectors (em versões antigas, "Integrations").
  2. Clique em Add custom connector.
  3. Cole a URL: https://aura-mcp-production.up.railway.app/mcp?key=AURADTCACCESS
  4. Salve. A base aparece como Aura na lista de conectores.
Como saber se conectou Você não precisa testar nada na mão: o setup (próxima seção) testa a conexão sozinho e avisa se algo estiver errado.
06Depois de instalar
Digite setup, e a Aura assume.

Com a Aura aberta, digite setup. Ela pergunta o idioma dos relatórios (português ou inglês) e faz 4 perguntas: a sua situação atual, o budget de anúncios, as ferramentas que você já tem (TrendTrack, SpyBox, Higgsfield) e o link da loja, se existir. No fim, ela aponta a fase certa pra começar.

Daí em diante o uso é sempre o mesmo: você digita o nome da fase, a Aura executa e indica a próxima. A ordem:

Pesquisaproduct research → market research → competitor analysis
Ofertamecanismo, preço, stack e garantia (offer)
Copyheadlines, página e argumentos (copy)
Lojadesign e deploy da página, tracking, checkout (page → tracking → checkout)
Tráfegocriativos, estratégia de ads, análise, escala (creatives → ad strategy…)
Retençãoemail e SMS depois do lançamento (retention)
O que aparece no seu computador

Cada produto vira uma pasta dentro de workspace/. As fases salvam os relatórios ali, e a Aura mantém na raiz do produto um arquivo chamado ABRIR-AQUI.html: o painel do produto. Abra no navegador pra ver o que está pronto, o que falta, o próximo passo e o link de cada relatório.

~ / aura-engine / workspace / meu-produto

meu-produto/

02-market-research/
03-competitor-analysis/
ABRIR-AQUI.htmlo painel · abra no navegador
Tudo é local, e só seu Os arquivos que a Aura cria existem apenas no seu computador. Não existe nuvem, não existe sincronização e ninguém além de você tem acesso a nada: nem às pesquisas, nem à oferta, nem aos números. O criador da Aura incluído.
Atualizações A Aura se atualiza sozinha uma vez por dia, ao abrir a primeira sessão, sem tocar nos seus arquivos de workspace/.
07Como usar de verdade
Nenhuma inteligência artificial acerta de primeira.

Isso não é um defeito da Aura; é a natureza da ferramenta, de qualquer modelo, de qualquer empresa. A primeira versão de qualquer coisa gerada por inteligência artificial é um rascunho bom, não um resultado final. A Aura foi desenhada em volta desse fato: ela apresenta, você reage, ela refina.

v1v2v3cada volta melhora
a aura gera
você lê e reage
ela refina
O jeito errado Mandar rodar tudo, não ler nada e responder "ok" e "continue" em todos os passos. O resultado é um negócio genérico, porque em nenhum momento entrou o SEU critério. Se você só aperta continuar, qualquer pessoa com a mesma ferramenta chega no mesmo lugar.
O jeito certo
  • Leia o relatório de verdade. Não a primeira dobra; o relatório. É nele que estão os números, as frases reais de cliente e as recomendações que você vai aprovar ou derrubar.
  • Reaja com precisão. "Esse ângulo está fraco", "essa frase não soa como a minha cliente", "refaz essa seção focando em X". Feedback específico gera versão melhor; "tá bom, continua" não gera nada.
  • Decida o que é seu. A Aura vai te trazer decisões que só você pode tomar: nome, cor, mecanismo, preço, posicionamento. Ela recomenda com base em método, mas o negócio é seu. Pense de verdade nessas horas.
  • Itere sem dó. A segunda versão é quase sempre muito melhor que a primeira, porque cada volta carrega o seu critério. Pedir 2 ou 3 rodadas de ajuste numa fase importante é o uso normal da Aura, não exceção.
Regra prática
Se você não discordou de nada, não leu com atenção.

Em toda fase existe pelo menos uma escolha que merecia o seu contraponto. Os melhores resultados vêm de quem trata cada relatório como uma reunião com um time sênior: lê, questiona, decide e só então avança.

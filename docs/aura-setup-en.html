01What Aura is (in 30 seconds)

Aura is your complete brand and marketing team inside an AI environment. It runs on Claude Code, right on your computer. It builds your ecommerce business in phases (research, offer, store, ads, retention), and each phase uses what the previous one discovered, so you never repeat information.

You drive everything by typing the name of what you want to do. No menus, no complicated configuration: you say "product research" or "copy", and Aura runs that step and tells you what comes next.

Why this exists Most people who teach ecommerce sell what's working today, and it goes stale within months. Aura codifies the fundamentals that don't age and lets the AI execute on them. Quality, automation, and speed in the same place.

03Installation, step by step
1. Install Claude Code

Open your Terminal and run the command for your system.

Mac:

curl -fsSL https://claude.ai/install.sh | sh

Windows:

irm https://claude.ai/install.ps1 | iex
2. Download Aura and open it

Clone the repository, enter the folder, and open the environment.

git clone https://github.com/reverseeth/aura-engine.git cd aura-engine claude
3. Connect the knowledge base

This command wires Aura to the base behind every recommendation. Run it in the Terminal, outside the Claude Code session (press Ctrl+C twice to exit, or open another Terminal tab):

claude mcp add --transport http aura https://aura-mcp-production.up.railway.app/mcp
Using Claude Desktop? Go to Settings → Integrations → Add Custom Integration and paste the same URL: https://aura-mcp-production.up.railway.app/mcp
4. Run the setup

With Aura open, type:

setup

Aura first asks which language you want your reports in (English or Portuguese) and then asks 4 quick questions (your current situation, your ad budget, the tools you already have, including your email platform, and your store link). It reads your page automatically and routes you to the right next step.

5. Next time

You don't need to repeat any of this. Open your Terminal and type:

aura

Aura keeps itself up to date: when it opens, it fetches the latest framework improvements automatically. To update by hand, enter the folder and run git pull.

Never delete the folder to "reinstall" All of your work (research, offers, copy, creatives) lives in workspace/, which exists only on your computer (there is no cloud copy). Deleting the folder or re-downloading everything over it erases that work. Before any big operation, copy workspace/ to a backup.
04Using Aura day to day

After the setup, the day to day is simple. You say what you need, Aura delivers, and it always tells you what the next step is.

1
Fire any phase by name.
Say "product research", "market research", "offer", "copy", "page", "creatives", "ad strategy", and so on. Aura runs the phase and points to what to run next.
2
Every product gets its own dashboard.
Open the ABRIR-AQUI.html file in the product's folder (that is the actual file name Aura generates; it keeps its Portuguese name, meaning "open here") to see what's already done, open any report, and know what to run next.
3
Follow the logical order.
Research (product → market → competition) → offer → copy → store (page → tracking → checkout) → creatives → audit → ads (strategy → analysis → scale) → post-launch (retention → bonus → recycling).
4
You never repeat information.
Each phase reads what the earlier ones produced. What you discovered in research feeds the offer, which feeds the copy, and so on.

06One thing to expect

Aura hands you a first draft to react to and refine, not a finished "done" on the first try. Tell it what to adjust (tone, angle, emphasis) and it iterates on what it already built.

The more you use it on a product, the sharper it gets: each phase leaves a trail the next one picks up. Start small, let each phase feed the next, and the whole thing gains consistency on its own.

The right pace
Start small. Let each phase feed the next.

You don't have to do everything today. Run one phase, react to the draft, move to the next. Aura keeps the context and tells you where you are whenever you come back.

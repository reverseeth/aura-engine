01What Aura is
A system that runs inside Claude Code.

Aura is an ecommerce brand-building system that runs inside Claude Code. Technically, it is three things:

  • Skills. Executable phases that cover the whole business, end to end: product, market and competitor research, sourcing, offer, copy, page, creatives, paid traffic, retention — plus the consultations you call when you need them: finance and projections, creators and ambassadors, promotions and Black Friday, hiring, operations and risk, expansion to Amazon and TikTok Shop. You trigger each phase by typing its name.
  • Rules. Permanent instructions for how the artificial intelligence works: quality standards, automatic checks before any launch, and protections for your data.
  • A connected knowledge base. More than 1,300 marketing, copy and paid media systems catalogued by name and address (Schwartz, Hopkins, Cialdini, Hormozi, and the complete brand-building method behind Aura). Before important decisions, Aura consults that base — and it consults everything that exists on the subject, not a sample. That is what grounds the recommendations in method rather than improvisation.
How the phases connect Each phase saves what it found in the workspace/ folder, and the next one reads those files before it starts. Research feeds the offer, the offer feeds the copy, the copy feeds the page. Nothing is lost and you never repeat information.

03Installation
Two commands and Aura is on your machine.
Mac

Open Terminal and run these, one at a time:

1 · install claude code
curl -fsSL https://claude.ai/install.sh | sh
2 · download aura and open it
git clone https://github.com/reverseeth/aura-engine.git
cd aura-engine
claude

If your Mac asks to install the "Command Line Tools" when you run git, accept. That is Apple's own installer.

Windows

Open PowerShell and run these, one at a time:

1 · install claude code
irm https://claude.ai/install.ps1 | iex
2 · download aura and open it
git clone https://github.com/reverseeth/aura-engine.git
cd aura-engine
claude

If the git command does not exist, install it first at git-scm.com/download/win (standard installation) and open PowerShell again.

What should happen The first time, Claude Code asks you to sign in. Use the account from your subscription. When the input field appears, Aura has loaded with it: it lives inside that folder.
Never delete the aura-engine folder to "reinstall" All of your work lives in the workspace/ folder, inside aura-engine, and exists only on your computer. Deleting the folder deletes the work with it. Aura updates itself every day; reinstalling is never necessary.
04The aura shortcut + permissions
Type aura. That is it, every day.

After this step, opening Aura becomes one word: you type aura in the terminal and Claude Code opens in the right folder, without asking permission at every step.

terminal
$aura
opening Claude Code in ~/aura-engine…
✻ Aura Engine · ready to work.
>market research
The no-interruptions mode

By default, Claude Code asks permission before every action. In a long Aura session that turns into dozens of approvals that break your flow. The bypass permissions mode turns those pauses off, and the shortcut below already comes with it enabled.

The first time, Claude shows a warning and asks for a single confirmation (accept it). The flag name is dramatic on purpose: with it, Claude acts without asking for approval at each step. Use this mode in the Aura folder, which has its own protections (such as the guard that mechanically blocks any commit of your data), and avoid using it in other folders.

Mac

Paste into Terminal (creates the shortcut and activates it in the current shell):

aura shortcut · mac
echo "alias aura='cd ~/aura-engine && claude --dangerously-skip-permissions'" >> ~/.zshrc
source ~/.zshrc

Aura creates a basic aura shortcut on its own in the first session. The command above installs the full version, with the no-interruptions mode; if the basic one already exists, the new one wins.

Windows

Paste into PowerShell (creates the shortcut in your profile):

aura shortcut · windows
if (!(Test-Path $PROFILE)) { New-Item -ItemType File -Path $PROFILE -Force }
Add-Content $PROFILE 'function aura { Set-Location "$HOME\aura-engine"; claude --dangerously-skip-permissions }'
. $PROFILE

If PowerShell complains about "execution policy" when it opens, run this once: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned and confirm.

Test it Close the terminal, open it again and type aura. If Claude Code opens in the aura-engine folder, you are ready. (If you cloned Aura to a different path, adjust the shortcut.)
05Connect the knowledge base
What grounds the recommendations.

The knowledge base holds more than 1,300 marketing, copy and paid media systems ready to consult. It is what backs Aura's decisions in every phase.

In Claude Code (automatic)

Aura Engine already ships with the base registered: there is nothing to configure. Open Claude Code (the aura command). The first time, a prompt appears asking whether you approve the aura server. Approve it, and you are connected.

Declined the prompt by accident? Run this outside a Claude session and open Claude Code again to approve:

show the approval prompt again · claude code
claude mcp reset-project-choices
In the Claude Desktop app
  1. Open Settings → Connectors (in older versions, "Integrations").
  2. Click Add custom connector.
  3. Paste the URL: https://aura-mcp-production.up.railway.app/mcp
  4. Save. The base appears as Aura in the connector list.
How to know it connected You do not need to test anything by hand: setup (next section) tests the connection on its own and tells you if something is wrong.
06After installing
Type setup, and Aura takes over.

With Aura open, type setup. It asks which language you want your reports in (Portuguese or English) and then asks 4 questions: your current situation, your ad budget, the tools you already have (TrendTrack, SpyBox, Higgsfield, Notion) and your store link, if you have one. At the end, it points you to the right phase to start from.

From there on the use is always the same: you type the name of the phase, Aura executes it and tells you the next one. The order:

Researchproduct research → market research → competitor analysis
Offermechanism, price, stack and guarantee (offer)
Copyheadlines, page and arguments (copy)
Storepage design and deploy, tracking, checkout (page → tracking → checkout)
Trafficcreatives, ad strategy, analysis, scale (creatives → ad strategy…)
Retentionemail and SMS — recovery flows before launch, campaigns after (retention)
Outside the sequence, the side consultations Beyond the phases in order, there are skills you call at any moment, by name, when the need shows up: finance (numbers, projections and how much you can spend on ads), sourcing (supplier, quotes and the real product cost), creators (user-generated content, seeding and ambassadors), promo (Black Friday, Q4 and any promotion, with the math redone before you turn the campaign on), team (when and how to hire), ops (account backups and plan B — worth it from day one) and marketplace (expanding to Amazon and TikTok Shop at the right time). Aura also points to each one on its own, the moment it makes sense.
What appears on your computer

Each product becomes a folder inside workspace/. The phases save their reports there, and Aura keeps a file called ABRIR-AQUI.html at the root of the product: the product dashboard. Open it in your browser to see what is done, what is missing, the next step and the link to every report.

Everything is local, and only yours The files Aura creates exist only on your computer. There is no cloud, no sync, and nobody other than you has access to any of it: not the research, not the offer, not the numbers. Aura's creator included.
Updates Aura updates itself once a day, when you open the first session, without touching your files in workspace/.
07How to actually use it
No artificial intelligence gets it right on the first try.

That is not a flaw in Aura; it is the nature of the tool, of any model, from any company. The first version of anything generated by artificial intelligence is a good draft, not a finished result. Aura was designed around that fact: it presents, you react, it refines.

v1v2v3every lap improves
aura generates
you read and react
it refines
The wrong way Telling it to run everything, reading nothing, and answering "ok" and "continue" at every step. The result is a generic business, because your judgment never entered it. If all you do is press continue, anyone with the same tool ends up in the same place.
The right way
  • Actually read the report. Not the first fold; the report. That is where the numbers are, the real customer phrases, and the recommendations you are going to approve or reject.
  • React with precision. "This angle is weak", "this sentence does not sound like my customer", "redo this section focusing on X". Specific feedback produces a better version; "looks good, continue" produces nothing.
  • Decide what is yours. Aura will bring you decisions only you can make: name, color, mechanism, price, positioning. It recommends based on method, but the business is yours. Think hard at those moments.
  • Iterate without mercy. The second version is almost always much better than the first, because every lap carries your judgment. Asking for 2 or 3 rounds of adjustment on an important phase is normal use of Aura, not an exception.
Rule of thumb
If you did not disagree with anything, you did not read carefully.

In every phase there is at least one choice that deserved your pushback. The best results come from people who treat each report as a meeting with a senior team: read, question, decide, and only then move on.
